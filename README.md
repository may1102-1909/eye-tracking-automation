# Hands-Free Eye Tracking Automation

An interactive Python application that tracks eye movements using computer vision to control the mouse cursor.

## Features
* Real-time face and iris tracking via MediaPipe
* Cursor movement automation using PyAutoGUI
* Custom thresholding for smooth interaction

## Tech Stack
* **Language:** Python
* **Libraries:** OpenCV, MediaPipe, PyAutoGUI
